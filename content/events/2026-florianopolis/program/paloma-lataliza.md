In this fun session, we will deploy a retro game (Sonic the Hedgehog) using containers running on Amazon ECS with Fargate, with the entire environment provisioned using Terraform and Terragrunt.

This is a mostly hands-on session where we will explore together the architecture of the application, the dependent services, and understand how containerized workloads are structured, deployed, and operated, along with IaC. We will discuss how containers are deployed with ECS, the pros of using Fargate for conducting workloads, and the organizational benefits for structured, modular Terraform projects for your cloud infrastructure and Terragrunt.

Attendees of the session will learn how to organize Terraform modules, manage environments with Terragrunt, use containers with ECS, and gain the knowledge to deploy containerized applications in a consistent and automatic manner. They will also learn about the positive side of using IaC to simplify cloud deployments and help teams migrate from code to a production-ready environment with more confidence and speed.
