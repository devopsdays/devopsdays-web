As plataformas internas de desenvolvedores foram construídas em torno de portais, catálogos de serviços e interfaces self-service. Hoje, os desenvolvedores interagem cada vez mais com as capacidades da plataforma por meio de agentes de IA para codificação, capazes de gerar infraestrutura, abrir pull requests e disparar deployments a partir de prompts em linguagem natural. À medida que esse modelo de interação evolui, os times de plataforma precisam garantir que esses sistemas operem de forma segura dentro dos limites operacionais estabelecidos.

Vamos explorar como os agentes de IA estão se tornando uma camada de interface complementar para plataformas como o Backstage. Você aprenderá como workflows de GitOps, aprovações de GitFlow, aplicação de políticas e admission controllers se tornam a camada de enforcement para operações conduzidas por agentes. Vamos demonstrar como servidores MCP conectam agentes às APIs da plataforma, como pull requests e verificações de políticas validam mudanças de infraestrutura antes do deployment, e como os times podem observar e governar workflows conduzidos por IA enquanto preservam os controles existentes. Platform engineering não está desaparecendo. Está evoluindo.
